# 家族のスケジュール

拓朗・五月・琥珀・生成の4人で共有するスケジュール帳です。GitHub Pages で公開すると `https://<ユーザー名>.github.io/<リポジトリ名>/family/` で開けます。

## できること

- **月・週・日の3つの表示**：月は一覧、週は1日ずつのカード、日は時間割（重なる予定は横に並びます）。左右スワイプで前後に移動します。
- **4人の色分け**：拓朗＝青、五月＝ピンク、琥珀＝琥珀色、生成＝緑、家族みんな＝紫。上のボタンで「その人だけ」に絞り込めます。1つの予定に複数人を選べます。
- **リアルタイム共有**：誰かが追加・修正・削除すると、数秒で全員の画面に反映され、「○○さんが『△△』を更新しました」と表示します。後から保存した内容が最新になります。
- **写真から取り込み**：おたよりや予定表を撮影すると文字を読み取り、日付・時刻・内容の候補を作ります。確認・修正してから登録します。読み取りは端末の中で行い、写真は外部に送りません（初回だけ文字認識データ約10MBを読み込みます）。
- **週間天気**：右上の角に7日分の天気マークと最高/最低気温。予定表の日付にも天気マークが付きます（[Open-Meteo](https://open-meteo.com/)、登録不要）。地域は設定で変更できます。
- **季節のデザイン**：表示している月に合わせて色と飾りが変わります（4月は桜、8月はひまわりと花火、11月はいちょうと紅葉、12月は雪とクリスマスなど）。祝日も表示します（[holidays-jp](https://holidays-jp.github.io/)）。
- ホーム画面に追加すると、アプリのように全画面で使えます。

## 家族で同期するための設定（最初に一度だけ・約10分）

`config.js` が空のままだと「お試しモード」で、予定はその端末だけに保存されます。家族で共有するには無料の Firebase（Google のサービス）を使います。

1. <https://console.firebase.google.com/> を開き、Google アカウントでログインします。
2. **プロジェクトを作成** → 名前（例：`family-calendar`）を入れて進みます。Google アナリティクスは **オフ** で構いません。
3. 左のメニューの **構築 → Authentication → 始める** → **ログイン方法** タブで **匿名** を選び、**有効にする** をオンにして保存します。
4. **構築 → Firestore Database → データベースの作成** → ロケーションは `asia-northeast1 (Tokyo)` → **本番環境モード** で作成します。
5. Firestore の **ルール** タブを開き、中身をすべて消して、このフォルダーの [`firestore.rules`](./firestore.rules) の内容を貼り付けて **公開** します。
6. 左上の歯車 **プロジェクトの設定** → 下の **マイアプリ** で `</>`（ウェブ）を押し、アプリ名（例：`family`）を入れて **登録** します。Firebase Hosting はチェック不要です。
7. 表示された `const firebaseConfig = { ... }` の `{ ... }` の部分を、`config.js` の `window.FAMCAL_FIREBASE = null;` の `null` と置き換えます。
8. 公開されたページを開き、⚙︎（設定）→ **家族との同期 → 新しく作る** を押します。**招待リンクをコピー** して LINE などで家族に送り、家族はそのリンクを開くだけで同じ予定表につながります。

`config.js` の値は公開されても問題のない識別子です。予定を読み書きできるのは家族コード（招待リンクに含まれる長いコード）を知っている端末だけなので、招待リンクは家族以外に送らないでください。

## ファイル

| ファイル | 内容 |
| --- | --- |
| `index.html` / `styles.css` | 画面と季節のデザイン |
| `app.js` | 月・週・日の表示、編集、天気、祝日、設定 |
| `sync.js` | 保存と同期（Firebase Firestore、未設定時は端末内） |
| `ocr.js` | 写真の文字読み取り（Tesseract.js）と予定候補の作成 |
| `config.js` | Firebase の設定値 |
| `firestore.rules` | Firestore のセキュリティールール |
